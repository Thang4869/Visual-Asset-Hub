================================================================================
                          WHAT YOU CAN DO
================================================================================

With TestFixture:
• Inherit from TestFixture for automatic database setup
• Access DbContext for database operations
• Use SaveChangesAsync() and ClearDatabaseAsync() helpers

With Builders:
• Create test assets fluently: new AssetBuilder().WithName("Test").Build()
• Create test collections: new CollectionBuilder().AsPublic().Build()
• Create test users: new UserBuilder().WithEmail("test@example.com").Build()

With ServiceBuilder:
• Configure DI: new ServiceBuilder().AddService<I, T>().Build()
• Add mocks: new ServiceBuilder().AddMockService<I>().Build()
• Add singletons: new ServiceBuilder().AddSingleton<I, T>().Build()

With Global Usings:
• Use xUnit, Moq, FluentAssertions without imports
• Use Entity Framework without imports
• Use Dependency Injection without imports
