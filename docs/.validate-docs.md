# Documentation Quality Validation

> **Mục đích**: Automated checklist để validate consistency của toàn bộ docs  
> **Last Updated**: 2026-04-06

---

## Validation Checklist

### Headers
- [ ] Mọi file có `> **Last Updated**: YYYY-MM-DD`
- [ ] Vietnamese titles cho non-template files
- [ ] English content preserved trong code examples

### Structure  
- [ ] § section numbering cho main content
- [ ] `---` dividers giữa các sections
- [ ] `> **Document End**` ở cuối mọi file

### Language
- [ ] Vietnamese descriptions và headers
- [ ] English technical terms (class names, APIs, properties)
- [ ] Consistent tone và terminology

### Links
- [ ] Internal links working
- [ ] Cross-references accurate
- [ ] No broken relative paths

---

## Quick Validation Commands

```bash
# Check for missing "Last Updated"
grep -L "Last Updated.*2026-04-06" docs/**/*.md

# Check for missing "Document End"  
grep -L "Document End" docs/**/*.md | grep -v "08_REPORTS"

# Check § section usage
grep -l "^## §[0-9]" docs/**/*.md | wc -l

# Validate Vietnamese titles
grep "^# " docs/**/*.md | grep -v "docs/08_REPORTS"
```
